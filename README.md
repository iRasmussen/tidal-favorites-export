# Tidal Favorites Export

Et Python-script, der eksporterer foretrukne kunstnere, album og numre fra Min musiksamling i Tidal.

Eksporten gemmes lokalt som både JSON og almindelig tekst.

## Filer

- `export_tidal_favorites.py`: Eksportscript
- `output/`: Lokale, genererede eksportfiler

Indholdet af `output/` versionsstyres ikke.

## Installation

Projektets Python-afhængigheder fremgår af `requirements.txt`.

## Brug

Kørselsvejledningen tilføjes, når scriptets godkendelsesmetode og kommandolinjeforløb er dokumenteret.

## Sikkerhed

Tokens, sessionsdata, adgangsoplysninger og personlige eksportfiler må ikke lægges i repositoryet.
